# Auto Backup v2

**Advanced backup management for Windows.**

Auto Backup v2 is the advanced version of the original **Auto Backup** application, developed by **Corrosion Labs**.

It provides automatic and manual backups, independent project configurations, backup history, and storage management through a simple desktop interface.

## Features

- **Automatic backups:** Create backups at configurable intervals.
- **Manual snapshots:** Create backups on demand with optional descriptions.
- **Multiple projects:** Manage independent projects, each with its own settings.
- **Backup retention:** Automatically remove the oldest automatic backups when the configured limit is reached.
- **Backup verification:** Check the integrity of generated ZIP archives.
- **Backup history:** Review completed backups and recorded errors.
- **Storage monitoring:** View disk space and backup usage.
- **Sound notifications:** Choose from built-in WAV sounds or use your own.
- **Multiple instances:** Work with different projects simultaneously.

## Requirements

- Windows
- Python and the required dependencies when running from source.
